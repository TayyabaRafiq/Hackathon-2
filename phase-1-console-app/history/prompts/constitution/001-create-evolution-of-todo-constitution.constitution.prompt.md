## Prompt

/sp.constitution

Project: The Evolution of Todo — Mastering Spec-Driven Development & Cloud-Native AI

Core Principles:
- Specification-first development (no code without spec)
- AI-generated implementation only (Claude Code)
- Human defines intent, constraints, and acceptance criteria
- Deterministic, testable behavior at every phase
- Iterative refinement of specs until correct output is achieved

Authority Rules:
- This Constitution is written once and governs all phases
- Specifications override implementations
- Manual code writing by the human is strictly forbidden
- Bugs are fixed by updating specifications, not editing code

Hackathon Phase Scope:
- Phase I: In-Memory Python Console App
  Stack: Python 3.13+, UV, Claude Code, Spec-Kit Plus
- Phase II: Full-Stack Web Application
  Stack: Next.js, FastAPI, SQLModel, Neon DB
- Phase III: AI-Powered Todo Chatbot
  Stack: OpenAI ChatKit, OpenAI Agents SDK, Official MCP SDK
- Phase IV: Local Kubernetes Deployment
  Stack: Docker, Minikube, Helm, kubectl-ai, kagent
- Phase V: Advanced Cloud Deployment
  Stack: Kafka, Dapr, DigitalOcean Kubernetes (DOKS)

Phase Constraints:
- Only features defined for the active phase may be implemented
- Future-phase technologies must not appear early
- Each phase requires independent specifications and spec history

Specification Standards:
- Every feature must have a Markdown specification
- Specs must be clear, unambiguous, and testable
- Specs must define behavior, inputs, outputs, and edge cases
- Spec history must be preserved for evaluation

Implementation Constraints:
- Console-only interaction in Phase I
- Web UI begins in Phase II
- Conversational AI allowed only in Phases III–V
- Kubernetes and cloud deployment allowed only in Phases IV–V

Success Criteria:
- All phase requirements implemented strictly via specs
- Code fully generated by Claude Code
- Clean, modular project structure
- Reproducible builds and deployments per phase
- Full compliance with hackathon phase deadlines and scoring

Acknowledge this Constitution as immutable unless explicitly revised via Spec-Kit Plus.
